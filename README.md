## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Development Server
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

The application runs on `http://localhost:5174/` (or port assigned by Vite).

### Production Build
```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```

The compiled assets will be output to the `dist/` folder, ready for zero-config deployment on Vercel, Netlify, or GitHub Pages.
